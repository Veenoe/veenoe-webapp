# Start Viva curriculum

The active catalog is `data/curriculum/ncert-cbse-2026-27.json`. It covers classes 5–12 with 129 class-subject entries, 1,656 chapters and 985 suggested topics.

The data contains only:

- Class: `id`, `classLevel`, `subjects`.
- Subject: `id`, `name`, `chapters`.
- Chapter: `id`, `name`, `difficultyLevel`, `topics`.
- Topic: `id`, `name`, `difficultyLevel`.

IDs are unique within their parent. Array order follows the chapter list. Difficulty is `null` until a rating scheme is agreed; it is not displayed or sent to the viva. English and Hindi contain lessons as chapters with empty topic lists. Other subjects include a few familiar practice topics where useful.

The UI supports one class, one subject, one chapter, and multiple topics within that chapter. Selecting a chapter initially covers the entire chapter. Choosing preset or custom topics narrows that chapter's focus. “Entire chapter” clears those focus choices and is generated by the UI rather than repeated in the catalog. Students can add or remove their own single-line topics (100 characters each). Choosing a different chapter clears its topic choices; choosing the same chapter preserves them. Changing class or subject clears descendants.

Selectors validate the catalog once. The reducer stores chapter IDs, topic IDs and custom topic text. The original Quick Setup card uses standard class, subject and chapter dropdowns, a checkbox dropdown for multiple topics, with a custom-topic input and Add button at the top and a Confirm button at the bottom. Add queues a custom topic and clears the input for another; choices apply only after Confirm; closing the dropdown discards pending changes. Class selection is saved to `veenoe_last_class` and restored on load for classes 5–12.

The `curriculum_selection` request field contains only class, subject and one selected chapter with its topics. An empty topics array means the entire chapter. The backend validates and persists the complete selection and passes it as JSON data to the assessment. New requests require exactly one chapter. The backend stores the selection under the same name. The assessment must not claim that every chosen area was covered during a five-minute session.

Existing chapter mappings were retained where no better HTML list was available. Older editions are included where useful; this catalog does not claim exact alignment with one current edition. Topics are product suggestions, not an exhaustive list of official headings. No PDFs or images were downloaded for this revision.

Class 9 Interdisciplinary Area still has no reliable chapter list and remains visible but unavailable. Its empty list is not replaced with invented chapters.

Validation: frontend selection/catalog tests, backend request/prompt/persistence tests, TypeScript, changed-file ESLint and the production build. No browser testing was performed.
